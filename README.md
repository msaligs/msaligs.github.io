## 🛠️ The Interactive Sandbox
This site is a live playground featuring custom-engineered components:
- **Neural Network Canvas**: High-performance HTML5 canvas mapping floating nodes with cursor-pull physics.
- **Paradox NLP Text Classifier**: Real-time ComplementNB TF-IDF text classifier simulation separating human-written text from standard AI boilerplate.
- **YOLO Bounding Box Simulator**: Dynamic object detection confidence threshold slider.
- **Live PyTorch Music Genre Classifier**: Dark-themed Gradio Web Component embedding my Hugging Face space for audio predictions.
- **Visits Counter**: Google Apps Script webhook integration logging visits in real-time.

---

## 💻 Tech Stack
- **Core**: Vanilla HTML5, ES6 JavaScript
- **Styling**: Modern HSL CSS3 (Responsive glassmorphism, blur filter orbs, flex/grid layouts)
- **APIs**: Gradio Web Component SDK, ipify, custom Google Sheets Macro API
- **Data**: JSON-driven architecture (`assets/data/`)
